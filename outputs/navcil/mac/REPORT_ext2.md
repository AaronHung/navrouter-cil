## 0-3　「拿掉 head」列是不是 FINAL-B 的定義

結論：**是**，直接引用（`ABLATION_full.csv` 的 `NOHEAD` ＝ MOE-3 的 S-R0f）。逐項對照：

| FINAL-B 定義的項目 | `NOHEAD` 列的實作 | 檔名：行號 | 相符 |
|---|---|---|---|
| s_i = s0_i（對該任務兩類文字的最大 cosine，z-score） | `s0, g = head.parts(Z, ft)` 取 s0，g 不用；s0 = `zscore(text_nav_feats(Z, f_txt)[:, 0])`，不含 head 的任何參數 | `scripts/moe2_common.py:161-163`；`selector/i6_expert.py:37-38`；`selector/flat_selector.py:28-33` | 是 |
| 四輪各 16、λ = 1.5 | `four_round(Z, s0, lam)`；BUDGET = 64、STEP = 16；λ 讀 `nc1/lambda.json`（1.5） | `scripts/moe2_common.py:163`；`selector/cil_ops.py:22-23`、`:39-45`；`scripts/nc1_pipeline.py:86-87` | 是 |
| 原始 Z 等權平均後 L2，再補 1 | `mean_norm(Z, idx)`：`X.mean(0)` 後 `F.normalize`；`aug` 接常數 1（float64） | `selector/cil_ops.py:31-36`；`scripts/nc5_report.py:151-154`；`scripts/moe3_common.py:242` | 是 |
| [v; 1] 累加式 ridge | 依序對已學任務 `A += XᵀX`；B 的類別欄 = 該類 x 之和；`solve(A + γI, B)` | `scripts/moe3_common.py:243`、`:250-258`、`:263` | 是 |
| γ | `moe3/hp.json` 的 `RDG:g0` = 1e-3（validation 選）；本批重選得同值 | `scripts/ext1_c.py:183`、`:39` | 是 |
| τ̂ 兩類內 argmax | 向量取 τ̂ 的版本；τ̂ 兩欄分數差 d ≥ 0 判第一類 | `scripts/ext1_c.py:100-101`、`:116-117`；`scripts/moe1_common.py:145-151` | 是 |
| TP | 階段 t 的 AR（γ = 1e-3）在已學任務中 argmax | `scripts/moe3_common.py:321-322`；`scripts/moe1_common.py:124-129` | 是 |

數值確認：K11(a) fold 1 的 train 2,273 張，不載入任何 head、由特徵檔依定義重算的 v 與 `NOHEAD` 所用的快取最大絕對差 0.0e+00；K11(b) fold 1 的 test 279 張完整推論，逐張判定不同 0 張。本批由快取算出的 `FINALB` 列與 `NOHEAD` 列逐折、逐階段相同（K9 最大絕對差 0.0e+00）。

一個實作細節（兩套相同，不是差異）：`four_round` 在選片前會把傳入的分數在同一張 slide 內再 z-score 一次（`selector/multiround.py:146-150`）；s0 本身已是 z-score，這一步只差一個 1/(1 + 1e-6) 的倍數，不改排序。
